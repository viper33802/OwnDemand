# OwnDemand Media Tape Asset Set

## Included
- Editable SVG masters for the icon, wordmark, and horizontal lockup
- Transparent PNG exports for light and dark use
- App icons from 16 px through 1024 px, including 32 px and 48 px
- Monochrome icon variants
- Android adaptive icon XML foreground/background resources
- Original concept board and palette reference

## Primary palette
- Cassette Violet `#4F46E5`
- Deep Plum `#24104F`
- Lavender `#A78BFA`
- Soft Lilac `#EDE9FE`
- Charcoal `#1F2937`

## Typography
Poppins SemiBold. Obtain Poppins from Google Fonts under its applicable open font license. Font files are not redistributed in this package. SVG wordmarks retain editable text. Convert text to outlines in a vector editor before final production if exact rendering must be preserved.

## Usage
Use the primary icon on light or neutral surfaces. Use the dark lockup on deep plum or charcoal backgrounds. Preserve clear space equal to roughly one cassette-reel diameter around the icon. Do not recolor with red/white or amber/black combinations.

## Android
Copy the contents of `android/drawable` and `android/mipmap-anydpi-v26` into the matching `res` directories. Raster PNGs are also available for legacy launcher resources.
